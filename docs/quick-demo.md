# Interactive Demo

The fastest way to try SO-CRATES is with our online interactive demo:

[https://so-crates.org/demo](https://so-crates.org/demo)

Please note the following:

- This is a cloud-based service, so please do not upload sensitive files or share any other sensitive information
- Free accounts are limited to 60 minutes of usage before the instance is automatically terminated
- If you need a private or permanent instance of SO-CRATES, then you can head to [Installation](installation/index.md) to set up your own local instance
